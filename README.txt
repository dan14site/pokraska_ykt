ПОКРАСКА 14 — сайт + визитка
=============================

ЧТО В АРХИВЕ
------------
site/index.html      — готовый сайт (весь файл самодостаточный: картинки внутри,
                        ничего дополнительно загружать не нужно)
site/assets/         — те же картинки отдельными файлами (на случай, если
                        захотите менять фото — тогда впишите src="assets/имя.jpg")
vizitka.html         — визитка 90×50 мм с QR-кодом (открывается в браузере,
                        печатается по размеру визитки)
qr.png               — QR-код отдельной картинкой (700×700 px)
make_qr.py           — генератор QR: python3 make_qr.py "https://ваш-адрес"

КАК ВЫЛОЖИТЬ САЙТ (2 минуты, бесплатно)
---------------------------------------
Вариант А — Netlify Drop:
  1. Откройте https://app.netlify.com/drop
  2. Перетащите папку site целиком (или один index.html)
  3. Получите адрес вида https://имя.netlify.app — он сразу работает

Вариант Б — GitHub Pages:
  1. Создайте репозиторий, загрузите index.html в корень (папку assets — по желанию)
  2. Settings → Pages → Branch: main, папка / (root) → Save
  3. Через 1–2 минуты сайт откроется по адресу https://логин.github.io/репозиторий/

ВАЖНО ПРО QR-КОД
----------------
Сейчас в QR-коде зашит адрес-заглушка: https://pokraska14.github.io/
После публикации сайта сделайте QR с настоящим адресом:

    pip install qrcode      (один раз)
    python3 make_qr.py "https://ваш-настоящий-адрес"

Скрипт перезапишет qr.png. Эту картинку нужно вставить в визитку:
в файле vizitka.html найдите строку  <img src="data:image/png;base64,...">  рядом
с class="qr" и замените её на  <img src="qr.png" alt="QR-код">  (файл qr.png
положите рядом с vizitka.html).

ПЕЧАТЬ ВИЗИТКИ
--------------
vizitka.html → Ctrl+P → размер бумаги «90 × 50 мм» (или A4 без масштабирования,
визиток на листе — 10) → «Фон и графика: включить».
Печатать лучше на плотной бумаге 250–300 г/м².
