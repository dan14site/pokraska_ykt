ПОКРАСКА 14 — сайт для GitHub Pages

1. Распакуйте архив.
2. Загрузите index.html и папку assets в корень репозитория GitHub (не загружайте сам ZIP).
3. Если GitHub спросит подтверждение, нажмите Commit changes.
4. В настройках Pages должна быть выбрана нужная ветка и папка корня (/root).

Главный файл: index.html
Изображения сайта находятся в папке assets.
